
# Energy-Efficient Resource Allocation in 6G Networks

## Project Overview
This project focuses on simulating an energy-efficient 6G wireless network using Python.

The goal is to optimize power allocation and reduce energy consumption while maintaining good network performance.

## Objectives
- Simulate a wireless network with multiple users.
- Model channel conditions and traffic demand.
- Implement traditional power allocation.
- Develop an energy-efficient resource allocation algorithm.
- Compare energy consumption, throughput, and latency.
- Visualize simulation results.

## Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- SciPy
